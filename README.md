# DevOps Bash Scripts

A collection of Bash scripts for Linux system administration
and DevOps automation.

## Purpose

This project helps me practice Bash scripting and automate
common Linux administration tasks.

## Scripts

| Script | Description |
|---|---|
| system_info.sh | Displays Linux system information |
| disk_usage.sh | Checks disk space |
| backup.sh | Backs up a directory |
| service_check.sh | Checks service status |
| log_monitor.sh | Searches logs for errors |

## Requirements

- A Linux system or virtual machine
- Bash shell

## How to Run

Clone this repository:

git clone YOUR_REPOSITORY_URL

Move into the repository:

cd devops-bash-scripts

Run the system information script:

bash scripts/system_info.sh
